## Introduction

This is a fun and interactive command-line JavaScript Quiz Application designed to test your JavaScript knowledge. The quiz presents multiple-choice questions and keeps track of your score throughout the game. A timer runs in the background, adding a layer of challenge as you race against the clock!

---

## Features

- Multiple-choice questions with four options.
- Real-time countdown timer.
- Score tracking system.
- Auto-advancing questions based on the timer.
- End-of-quiz score summary.

## Installation

### Prerequisites

- **Node.js** must be installed on your system. You can download and install it from the official [Node.js website](https://nodejs.org/).

### Steps to Install and Run the Quiz Application

1. Clone or download the repository from GitHub or copy the provided source code.
2. Open your terminal and navigate to the folder where the `quiz.js` file is located.
3. Run the following command to start the quiz:

   ```bash
   node quiz.js
